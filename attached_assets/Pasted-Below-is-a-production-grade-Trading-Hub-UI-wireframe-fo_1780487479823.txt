📊 COMPONENT BREAKDOWN
1. 🧭 TOP BAR (INSTITUTIONAL STATUS STRIP)
Purpose:

Real-time trading snapshot like a prop desk terminal.

UI Elements:
Date (GMT+1)
Account Balance
Daily P/L
Risk Used %
Open Trades Count
News Countdown Timer
Example:
Balance: $5,240 | P/L: +2.1% | Risk: 0.9% | Trades: 2 | ADP: 01:22
2. 📌 DAILY BIAS PANEL (CORE EDGE MODULE)
Layout:
XAUUSD BIAS: BEARISH

DXY: STRONG ↑
Yields: RISING ↑
Sentiment: RISK OFF / NEUTRAL
Liquidity Target: PDL / Weekly Low
Add toggles:
Bullish / Bearish / Neutral
Session tag (London / NY)
3. 📉 ACTIVE TRADES PANEL
Each Trade Card:
XAUUSD SELL
Entry: 2335.20
Current: +12.5 pips
Risk: 0.5%
Status: Running

[View] [Close] [Edit]
Features:
Live P/L tracking
Partial close option (future upgrade)
Tag: SMC / ICT / Breakout
4. ⚖ RISK SNAPSHOT MODULE
UI Box:
Risk per trade: 0.5%
Max Daily Loss: 2%
Used: 1.2%
Remaining: 0.8%

Safe Zone: ACTIVE / WARNING / BREACH
5. ⚡ QUICK ACTIONS BAR

Buttons:

➕ New Trade
🧠 Add Bias Note
📸 Upload Screenshot
📊 Open Risk Calculator
📅 Add News Event

Style:

Glassmorphism buttons
Hover glow effect

🔥 KEY DESIGN PRINCIPLE

This is not a dashboard.

It is:

A decision execution terminal for a discretionary trader

Everything must answer:

“Should I trade now?”
“What is my risk exposure?”
“Where is liquidity?”
“What is the macro bias?”
